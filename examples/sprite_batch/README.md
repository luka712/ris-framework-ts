# Sprite batch example

Loads `assets/kodim23.png` through `framework.content.loadTexture2DAsync` and draws it once as a single sprite with `framework.spriteBatch`.

Run from the repo root:

```sh
npm run dev:examples      # then open /sprite_batch/
npm run build:examples    # writes examples/dist/
```

## Image

`assets/kodim23.png` is image 23 (parrots) from the Kodak Lossless True Color Image Suite, downloaded from <http://r0k.us/graphics/kodak/> and resized from 768×512 to 512×341. Kodak released the suite for unrestricted use.
